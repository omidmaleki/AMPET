# apps/web-admin — پنل ادمین Next.js (SP-00 اسکافولد)

> اسکافولد دستی است چون `create-next-app` روی ماشین فعلی اجرا نشده. با نصب Node کافی است:

```bash
cd apps/web-admin
npm install
npm run dev      # http://localhost:3100
```

## محتوا

- `styles/tokens.css` — توکن‌های دیزاین‌سیستم هم‌ارز Flutter (M-00.7)
- `app/layout.tsx` — `dir="rtl"` + فونت Vazirmatn از توکن‌ها
- `app/page.tsx` — صفحه اسکلت

## نکته

صفحات واقعی ادمین (گروه «محتوای کالا» صفحه ۱۳/۱۴ و …) در SP-03/SP-04 و پنل کامل در SP-15.
