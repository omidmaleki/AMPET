## ۱. خلاصه اجرایی

**AMPET** یک سوپر اپلیکیشن دوطرفه (مارکت‌پلیس + خدمات) در حوزه پت‌شاپ و دامپزشکی است؛ اندروید + iOS (یا Web App برای iOS).

هدف: اتصال **مالکان حیوانات (Customer)**، **ارائه‌دهندگان (Seller: پت‌شاپ، کلینیک، بیمارستان، گرومر، دامپزشک، پانسیون، عمده‌فروش، واردکننده)** و **ادمین پلتفرم** در یک پلتفرم واحد.

تیم فعلی: ۲ نفر (مدیر پروژه + توسعه‌دهنده شریک).
تکنولوژی مبنا: Microservices + PostgreSQL + Bot Crawler.

خروجی‌های این پروپوزال:
- تعریف اسکوپ دقیق فازها
- لیست صفحات و وایرفریم‌ها (۲۸ تصویر آماده در `wireframes/`)
- مدل درآمدی
- زمان‌بندی و بودجه پیشنهادی
- شرایط همکاری

## ۶. فرآیندهای کلیدی (خلاصه برای کارفرما)

1. **تأیید فروشنده:** ثبت‌نام OTP → تکمیل مدارک اختصاصی نوع → «در انتظار تأیید» → چک‌لیست ۵ موردی ادمین → تأیید/رد/نقص (دلیل اجباری) → فعال‌سازی + سطح «تازه‌کار». مهلت تکمیل نقص: ۷ روز.
2. **تأیید محصول:** پیش‌بررسی خودکار ۱۰ شرطی (۳ تا ۱۲ تصویر، عنوان ۱۰-۸۰، توضیح ۵۰+ حرف و...) → صف ادمین (SLA ۲۴ ساعته، دارو ۷۲ ساعته) → چک‌لیست ۱۰ موردی → انتشار یا رد (۳ تلاش، سپس تعلیق ۷ روزه).
3. **پرداخت و تسویه:** اسکرو (نگهداشت امانی) تا تحویل با کد ۶ رقمی + عکس → آزادسازی → تسویه ۱۴ روزه. روش‌ها: درگاه بانکی + زرین‌پال + کیف پول + اعتبار BNPL.
4. **لغو/مرجوعی/بازگشت وجه:** جدول لغو سفارش و نوبت + SLA بازگشت وجه + فاکتور رسمی.
5. **بیمه:** استعلام (سن ≤۸ سال، واکسن فعال) → پرداخت → بررسی ادمین (۳ روز) → صدور PDF+QR → ادعا (۵ روز بررسی) → واریز به کیف پول.
6. **پت‌تکسی:** قیمت شفاف → رزرو ۱۰ دقیقه‌ای پیک → اسکرو → ردیابی زنده + تماس ایمن → تحویل با کد ۶ رقمی.

جزئیات کامل در سند فنی و سند اصلی.

## ۸. تکنولوژی پیشنهادی (خلاصه مدیریتی — جزئیات در سند معماری)

- اپ: Flutter (یک کدپایه Android+iOS) — جایگزین: React Native
- بک‌اند: Node.js (NestJS) میکروسرویس — ۱۲ سرویس (Auth, User, Marketplace, Booking, Payment, Notification, Insurance, Transport, Cafe, Livestock, Crawler Bot, Reminder)
- دیتا: PostgreSQL 16 + Redis + RabbitMQ + Elasticsearch
- ذخیره‌سازی: S3-compatible — چت: WebSocket — نقشه: OSM/Mapbox
- پرداخت: درگاه بانکی + زرین‌پال — پیامک: کاوه‌نگار و مشابه — مانیتورینگ: Prometheus/Grafana/Sentry — CI/CD: GitHub Actions/GitLab CI
